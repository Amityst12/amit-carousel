# AmitCarousel — מפעל קרוסלות לאינסטגרם 🎠

> **TL;DR (English):** a local carousel generator for Instagram (Next.js + Bun, Hebrew/RTL friendly, 1080×1350) with a Claude Code skill (`/amit-carousel`) that researches, writes, checks and exports carousels — plus optional scripts to archive, publish to Instagram via the official API, schedule with Claude scheduled tasks, and pull analytics. Quick start: `cd skill/template && bun install && bun dev --port 3333` → open http://localhost:3333.

מערכת מקומית שהופכת נושא, טקסט, קישור או צילום מסך לקרוסלה מעוצבת לאינסטגרם: תצוגה חיה בדפדפן, ייצוא PNG באיכות העלאה, בודק חוקים אוטומטי, ארכיון, ואופציונלית גם פרסום ומדידה דרך ה-API הרשמי של אינסטגרם. אפשר לעבוד איתה **ידנית** (עורכים קובץ אחד) או **עם Claude Code** (הסקיל `/amit-carousel` מלווה אתכם מהרעיון עד ה-PNG).

נבנתה על ידי **עמית יהושפט** — [@amit.yehoshaphat באינסטגרם](https://www.instagram.com/amit.yehoshaphat/). אם זה עוזר לכם: ⭐ **תנו Star לרפוזיטורי** ו**עקבו אחרי העמוד** — זו הדרך הכי טובה להגיד תודה ולעזור לפרויקט לצמוח 🙏

## מה מקבלים
- **מחולל קרוסלות** (Next.js) עם תצוגה חיה: פורמט 4:5 (1080×1350), עברית מימין לשמאל (גופן Heebo), עיצוב נקי בכחול-לבן שאפשר להחליף בלחיצה (גופן, רקע, צבע דגש, רקע דקורטיבי).
- **ממשק דו-לשוני:** הכלי באנגלית כברירת מחדל, עם מתג **EN / HE** בפינה למעבר לעברית (שמות הכפתורים בתיעוד הם באנגלית).
- **13 סוגי שקפים**: hook, body, list, stats, quote, checklist, process, number, emoji, image, bars, cta, ועוד.
- **מרקר מכחול (brush)** שמדגיש ביטויים, **חצי החלקה** מצוירים, **דקורציות SVG** (3 צבעים), סטיקרים (אופציונלי), נקודות מיקום שקף, פוטר עם אווטאר ו-@.
- **בודק חוקים** (`scripts/check-carousel.mjs`): מקסימום 7 שקפים, מבנה Hook→CTA, מילת מפתח, כיתוב בשתי שורות, קריאות, ועוד.
- **שני סקילים ל-Claude Code:** `/amit-setup` (הגדרה חד-פעמית: התקנה, המותג שלכם, סטיקרים, חיבור אינסטגרם) ו-`/amit-carousel` (מחקר ואימות עובדות, כתיבה לפי נוסחת Hook/Retain/Reward/CTA, בדיקה וייצוא).
- **אופציונלי:** ארכיון מסודר עם נתוני מדידה, פרסום לאינסטגרם דרך ה-API הרשמי (פקודה אחת), תזמון עם Claude, אנליטיקה, העתקה ל-Google Drive, תמלול YouTube.

```bash
cd amit-carousel/skill/template

bun dev --port 3333
```
פתחו **http://localhost:3333** — תראו את הקרוסלה הדוגמה, סרגל כלים (פורמט, גופן, רקע, צבע) וכפתורי ייצוא.

**עם Claude Code:** פתחו את התיקייה הראשית של הפרויקט (`amit-carousel/`) ב-Claude Code וכתבו קודם `/amit-setup`, ואחר כך `/amit-carousel תכין לי קרוסלה על …`. הסקילים יתקינו, יפעילו שרת ויכירו אתכם בעצמם.

## הגדרה ראשונה: המותג שלכם
כל ההגדרות האישיות נמצאות בראש הקובץ **`skill/template/src/slides.ts`** (או שהסקיל עושה את זה בשבילכם):

| מה | איפה בקובץ | הסבר |
|---|---|---|
| ה-@ שלכם | `HANDLE` | כתבו עם תו בלתי נראה לפני ה-@ (`"‎@your.handle"`) כדי שה-@ יישאר משמאל בעברית. מופיע בפוטר ובשקף ה-CTA. |
| תמונת פרופיל | `AVATAR_SRC` | שימו תמונה מרובעת ב-`skill/template/public/images/avatar.png` וכתבו `"/images/avatar.png"`. `null` = ללא. |
| צבע הדגש | `DEFAULT_ACCENT` | `blue` (ברירת מחדל), `red`, `teal`, `coral`, `orange`, `violet`, `lime`, `fuchsia`, `pink`, `amber`, `yellow`. |
| בהיר/כהה | `DEFAULT_SURFACE` | `light` (ברירת מחדל), `white`, `dark`, `paper`, `gradient`, `pastel`, `neon`, `ember` |
| גופן | `DEFAULT_FONT` | `hebrew` (Heebo, לעברית), או `clean`/`minimal`/`editorial`/`mono`/`condensed` ללועזית. |
| רקע | `DEFAULT_BG` | `lines` (קווים אלכסוניים, ברירת מחדל), `grid`, `blobs`, `paper`, `noise`, `glow`, `bignumber`, `none` |
| פורמט | `DEFAULT_FORMAT` | `threads-4x5` (פיד אינסטגרם אנכי, מומלץ), `instagram-square`, `story-9x16`… |
| חץ החלקה אוטומטי | `AUTO_ARROW` | חץ מצויר בפינה על כל שקף חוץ מהאחרון. |

**התחלה נקייה:** הסקיל `/amit-setup` עושה את זה בשבילכם. ידנית: העתיקו את `skill/template/starter/slides.starter.ts.txt` מעל `skill/template/src/slides.ts` — קרוסלת דוגמה של 5 שקפים שלא צריכה אף קובץ תמונה.

## יצירת קרוסלה
### דרך א׳: עם Claude Code (מומלץ)
1. הריצו פעם אחת `/amit-setup` (ה-@ שלכם, שפה, קהל יעד, צבע, תמונת פרופיל, סטיקרים; נשמר ב-`config/brand.md`). אחר כך פתחו את הפרויקט ב-Claude Code וכתבו `/amit-carousel` (או "תכין קרוסלה על …").
2. הסקיל קורא את `config/brand.md`, כך שלא שואלים אתכם שוב.
3. תנו נושא: טקסט, קישור, צילום מסך, ריל או סרטון YouTube. הסקיל יחקור, יאמת עובדות מול מקורות, ויציע **סוג פוסט וסדר שקפים** לפני שהוא בונה.
4. הוא יכתוב את `slides.ts`, יריץ את הבודק, ירנדר ויבדוק כל שקף, ויציג לכם שקפים + כיתוב. אתם מאשרים או מבקשים שינויים.
5. מאשרים → ארכיון → ייצוא PNG.

### דרך ב׳: ידנית
1. ערכו את `skill/template/src/slides.ts`: מערך `SLIDES` (כל איבר = שקף), ו-`POST_META` (שם, כיתוב, מילת מפתח, מקורות).
2. שמרו — הדפדפן מתרענן לבד.
3. לחצו על הכפתור הירוק **Export All** בפינה הימנית-עליונה לייצוא כל השקפים כ-PNG (2160×2700, איכות העלאה), או **Export PDF** לקובץ אחד. לחיצה על שקף בודד מייצאת אותו לבד.

> בכל מחרוזת השתמשו ב-`\n` לשבירת שורה — לעולם לא שורה חדשה אמיתית בתוך מרכאות.

## סוגי שקפים ושדות
פירוט מלא של המנוע המקורי: [`skill/SKILL.md`](skill/SKILL.md) ו-[`skill/template/src/lib/types.ts`](skill/template/src/lib/types.ts). הנה העיקרי:

| סוג | מתי | שדות עיקריים |
|---|---|---|
| `hook` | שקף 1 | `text`, `highlight`, `subtitle`, `heroName` (שם גדול בצבע דגש), `heroIcon` (לוגו), `keyword` (מילת מפתח כתווית) |
| `number` | שקף 2 — "הוק שני" | `bigNumber`, `title`, `text`, `highlight`, `teaser` ("ובהמשך: …") |
| `body` | הסבר | `title`, `text` או `points[]` (✓/✗), `bigTitle` |
| `list` | רשימה ממוספרת | `title`, `items[]` |
| `process` | צעדים | `title`, `steps[{title,text}]`, `text` (שורת תוצאה) |
| `stats` | מספרים | `title`, `stats[{value,label}]`, `text` |
| `bars` | גרף עמודות | `title`, נתונים |
| `quote` | ציטוט | `text`, `author`, `role` |
| `image` | צילום מסך כראיה | `title`, `imageSrc`, `imageCaption` |
| `checklist`, `emoji` | רשימת סימון / אייקון ענק | ראו `types.ts` |
| `cta` | שקף אחרון | `text`, `highlight`, `ctaLabel` ("עקבו" / "תגיבו ״מילה״"), `handle`, `subtitle`, `subtitleHighlight` |

**שדות משותפים לכל שקף:** `badge` (תג קטן, "01"), `highlight` + `highlightStyle` (`marker` = מרקר בהיר; `brush-solid` = מכחול מלא לקריאה לפעולה), `sticker` + `stickerPos`, `decor[{name,color,w,top/left/right/bottom,rotate}]`, `arrow` (`false` = בלי חץ).

**הערות:** `highlight` חייב להופיע בדיוק כפי שהוא בתוך הטקסט, ובשורה אחת (שורה חדשה בתוך הביטוי = המרקר לא יצויר). הימנעו מסוג `comparison` (אדום/ירוק קשיחים שמתנגשים עם המותג) — השתמשו ב-`stats`.

## כללי כתיבה
הכללים האלה הם הלב של "מה שעובד" בקרוסלות (והבודק אוכף חלק מהם):

- **עד 7 שקפים.** פחות זה בסדר.
- **שקף 1 — Hook:** הבטחה או תוצאה שהקורא רוצה + סקרנות. פוסט על כלי/מוצר מוגדר? שם המוצר ענק (`heroName`). פוסט תוצאות? "מ-X ל-Y". לעולם לא הבטחה שאי אפשר לעמוד מאחוריה.
- **שקף 2 — הוק שני:** מספר מפתיע או טענה נועזת (אינסטגרם מציגה מחדש את שקף 2 למי שדילג על הפוסט). הוסיפו `teaser` שמושך הלאה.
- **שקפים 4–5 — Reward:** התשובה המלאה, הקונקרטית והמעשית להבטחה בהוק. ספציפי, בשפה פשוטה, משהו שאפשר לעשות או להעתיק *עכשיו*. לא בשקף 2–3 ולא באחרון.
- **CTA (קריאה לפעולה):** לכל היותר **אחת** בהוק, לכל היותר **שתיים** בשקף האחרון (למשל: עקבו + שמרו, או תגיבו מילת מפתח + שמרו). תנו סיבה אמיתית. בלי דחיפות מזויפת.
- **מילת מפתח (אופציונלי):** "תגיבו ״X״ ותקבלו מדריך בפרטי": המילה מופיעה בהוק ובשקף ה-CTA, בולטת (תווית/כפתור), ובשורה הראשונה של הכיתוב. ה"מתנה" היא מדריך כתוב קצר ומאומת (`guides/<נושא>-guide.md`).
- **שפה פשוטה:** תניחו שהקורא לא מכיר את הנושא. משפטים קצרים. בלי ז׳רגון. ניסוח בגוף ראשון יחיד כשזה הניסיון שלכם.
- **אמינות:** רק עובדות ממקור מצוין, מספרים מדויקים, ציינו כשהמספרים הם של החברה. לעולם לא להמציא ניסיון אישי, תוצאות או ציטוטים. שקף "חשוב לדעת" רק כשיש מגבלה/סיכון אמיתי.
- **כיתוב (Caption):** **שתי שורות בדיוק**, בלי האשטגים כברירת מחדל. כל שורה **מתחילה במילה בעברית** (שורה שמתחילה באנגלית מוצגת משמאל לימין ומקלקלת את הפיסוק), עד ~70 תווים לשורה. עם מילת מפתח: שורה 1 = "תגיבו ״X״ ו…" + מה מקבלים.
- **עברית:** בלי ניקוד; אנגלית רק לשמות מוצרים; פקודות/דוגמאות באנגלית עטופות ב-U+2066…U+2069; לא שרשראות של שמות לועזיים בתוך משפט עברי; כיתובי תמונות מתחילים בעברית.
- **תמונות:** מדי פעם, צילום מסך אמיתי של דף המקור כשקף "ראיה" (עד ~64% מגובה השקף, כותרת קצרה למעלה, שורה מודגשת למטה).

## בדיקת איכות
```bash
bun scripts/check-carousel.mjs
```
מדפיס **ERROR** (חובה לתקן, קוד יציאה 1) ו-**WARN** (לשקול). בודק: עד 7 שקפים, hook ראשון ו-CTA אחרון עם כפתור, כל `highlight` באמת קיים בטקסט, מגבלות קריאה לפעולה, מילת מפתח בהוק/CTA/כיתוב, כיתוב בשתי שורות שמתחילות בעברית, קבצי תמונה/סטיקר קיימים, `POST_META` מלא ועוד.
> חלק מהכללים הם לעברית בלבד. אם אתם כותבים בשפה אחרת, תתעלמו מאזהרות שמתייחסות לעברית.

## אופציונלי: פרסום לאינסטגרם ותזמון
**כל החלק הזה אופציונלי.** אפשר להעלות ידנית ולא להשתמש בו בכלל.

### מה זה נותן
פקודה אחת מעלה קרוסלה מהארכיון לחשבון שלכם דרך ה-API הרשמי של אינסטגרם: ממירה ל-JPEG 1080×1350, מעלה זמנית ל-Drive (כתובות ציבוריות שאינסטגרם דורשת), מפרסמת, ומנקה.

### הגדרה חד-פעמית
1. **חשבון אינסטגרם מקצועי (Business או Creator) — חובה.** חשבון אישי לא יעבוד עם ה-API. המרה חינמית: הגדרות ← Account type and tools ← Switch to professional account.
2. **אפליקציית Meta:** developers.facebook.com ← My Apps ← Create App ← הוסיפו את המוצר **Instagram** ← *API setup with Instagram login*. הוסיפו את חשבון האינסטגרם שלכם לאפליקציה (תפקיד בודק/מפתח). (שמות התפריטים ב-Meta משתנים מדי פעם.)
3. **טיפ:** את שלבי Meta אפשר למסור לסוכן דפדפן (Claude Cowork): הפרומפט המוכן ב-[docs/cowork-instagram-setup-prompt.md](docs/cowork-instagram-setup-prompt.md). אחרת, בצעו בעצמכם. **הרשאות** (scopes) לבקש: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_insights` (לאנליטיקה). לחשבון שלכם בלבד אין צורך ב-App Review.
4. **הנפקת טוקן:** באותו מסך *Generate access token* לחשבון שלכם ← אשרו. מתקבל טוקן ארוך-טווח (**60 יום**).
5. **קובץ הסודות:** העתיקו `.instagram.env.example` ל-`.instagram.env` ומלאו `IG_APP_ID`, `IG_APP_SECRET`, `IG_ACCESS_TOKEN`, `IG_USER_ID`. הקובץ כבר ב-`.gitignore`. **לעולם לא** להדביק את הערכים בצ׳אט, בלוגים, בצילומי מסך או לדחוף ל-git.
6. **בדיקת חיבור (קריאה בלבד, לא מפרסם):** `bun scripts/ig-check.mjs` — אמור להדפיס שם משתמש, סוג חשבון ומדדים.
7. **אירוח תמונות ב-Google Drive:** התקינו Google Drive for Desktop. בדרייב צרו תיקייה `ig-publish` ← שתפו "כל מי שיש לו הקישור — צפייה" (Anyone with the link, Viewer) ← העתיקו את מזהה התיקייה מכתובת ה-URL. העתיקו `config/ig-config.example.json` ל-`config/ig-config.json` ועדכנו את `driveHost.dir` (נתיב התיקייה המקומית) ואת `driveHost.publicFolderId`.
   > הקבצים בתיקייה ציבוריים ("לכל מי שיש קישור") רק בזמן הפרסום, ונמחקים מיד אחריו. אלה אותן תמונות שבכל מקרה יתפרסמו באינסטגרם.

### שימוש
```bash
# הרצת ניסיון — בונה את הקונטיינרים באינסטגרם ובודק, לא מפרסם כלום
bun scripts/ig-publish-auto.mjs <slug> --dryrun

# פרסום עכשיו (אחרי שאישרתם בעצמכם!)
bun scripts/ig-publish-auto.mjs <slug> --approved
```
`<slug>` = שם התיקייה ב-`Published/` (אפשר גם רק החלק אחרי התאריך).

**כללי בטיחות מובנים:** הפרסום דורש את הדגל `--approved` (אישור מפורש שלכם — מאשרים רק כשבאמת רוצים להעלות); הכיתוב חייב להיות שתי שורות; כל התמונות חייבות להיות 4:5. עם Claude: "מאושר" = ארכיון בלבד; "תעלה" = בקשת פרסום שחייבת לכלול **מתי** (תאריך+שעה, או "עכשיו"). בלי "מתי" — Claude ישאל.

### תזמון
ל-API של אינסטגרם אין תזמון מובנה (נבדק: `scheduled_publish_time` מחזיר שגיאה 500). הפתרון: **משימה מתוזמנת חד-פעמית של Claude** שמריצה את אותה פקודה בזמן שביקשתם. בקשו מ-Claude: "תעלה את הקרוסלה X ב-15:00 ביום חמישי". דרישות: **המחשב דלוק, אפליקציית Claude פתוחה ו-Google Drive for Desktop רץ** בזמן הפרסום (אחרת הפוסט יעלה בהפעלה הבאה). את המשימה רואים ומבטלים בסיידבר "Scheduled". לחלופין, לתזמון נטיבי: Meta Business Suite.

### מגבלות ששווה להכיר
- JPEG בלבד, עד 10 תמונות בקרוסלה, כל התמונות נחתכות ליחס של הראשונה (אצלנו תמיד 4:5).
- **אי אפשר לערוך כיתוב דרך ה-API** — מתקנים לפני הפרסום.
- הטוקן פג אחרי 60 יום: הנפיקו מחדש ב-Meta (או חדשו עם `refresh_access_token` אחרי 24 שעות) ועדכנו את `.instagram.env`. כדאי לשים תזכורת ליומן.
- קריאת תגובות (`scripts/ig-comments.mjs`) ניסיונית: דורשת את ההרשאה `instagram_business_manage_comments`, ובפועל אצלנו היא לא התקבלה בטוקן; ספירת תגובות מילת מפתח נעשית ידנית.
